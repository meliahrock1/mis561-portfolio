**Certification - Introduction to Power BI:** MIS 561, 9/25/2026 (https://public.tableau.com/views/PowerBITrainingCertifications_17903843295320/PowerBIStory?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

In the course's previous Excel work, I had to manually clean and transform data before I could begin my analysis and visualizations. For example, in a previous assignment, we had to use Text to Columns in Excel to separate fields and then use Tableau to visualize the data. In Power BI, I can complete those transformations directly in Power Query, while the Applied Steps automatically keep a record of each change made to the data. For a dataset that needs to be updated or analyzed repeatedly, I would choose Power BI because those transformations become part of a repeatable process instead of something I would need to recreate manually in Excel. I would still use Excel for smaller or one-time analysis, but Power BI makes more sense when I expect the underlying data to change over time.
